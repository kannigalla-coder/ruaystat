# รวยสถิติ (RuayStat)

เว็บแอปสถิติสลากกินแบ่งรัฐบาล: สุ่มเลขจากสถิติที่เคยออกจริง ดูตารางความถี่ บันทึกเลข และตรวจรางวัล
ผลรางวัลดึงจาก glo.or.th อัตโนมัติด้วย GitHub Actions แล้วเก็บเป็นไฟล์ JSON ใน `data/` ไม่ต้องมีฐานข้อมูล

```
glo.or.th ──▶ GitHub Actions (วันที่ 1, 16 ฯลฯ หลัง 16:00) ──▶ data/*.json ──▶ GitHub Pages
```

## ขึ้น GitHub ครั้งแรก

1. สร้าง repository ใหม่ที่ github.com (ชื่อเช่น `ruaystat`) ไม่ต้องติ๊กสร้าง README
   - บัญชีฟรีต้องตั้งเป็น **Public** ถึงจะเปิด GitHub Pages ได้
2. ส่งโค้ดขึ้นไป (ในโฟลเดอร์นี้):
   ```
   git remote add origin https://github.com/<ชื่อผู้ใช้>/ruaystat.git
   git push -u origin main
   ```
3. ที่ repository → **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
4. ที่แท็บ **Actions** → เลือก **Deploy site** → **Run workflow** (ครั้งแรกครั้งเดียว ต่อไปจะ deploy เองทุกครั้งที่ push)
5. เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/ruaystat/`

หลังจากนี้ workflow **Update lottery results** จะดึงผลงวดใหม่เองทุกวันออกรางวัล ทุก 30 นาทีช่วง 16:00–20:30 น.
ถ้าอยากดึงทันที: Actions → Update lottery results → Run workflow

## ทำงานในเครื่อง

```
npm install          # ครั้งแรก (ติดตั้ง Tailwind สำหรับ build CSS)
npm run serve        # เปิดเว็บที่ http://localhost:5173
npm run build:css    # build css/app.css ใหม่ ทุกครั้งที่เพิ่ม/แก้ class ของ Tailwind ใน index.html หรือ js/
npm run fetch        # ดึงผลงวดล่าสุด
npm run backfill     # ดึงผลย้อนหลังตั้งแต่ 2016 (ข้ามงวดที่มีแล้ว)
```

> ดับเบิลคลิก `index.html` เปิดตรง ๆ ได้ แต่เบราว์เซอร์จะไม่ยอมให้อ่านไฟล์ `data/` แอปจะแสดง "ข้อมูลตัวอย่าง" แทน ใช้ `npm run serve` เพื่อดูผลจริง

## แผนผังไฟล์

| ไฟล์ | หน้าที่ | ตรวจอะไร |
|---|---|---|
| `index.html` | โครงหน้า: header, แถบแท็บล่าง, ลำดับโหลดไฟล์ | ลำดับ `<script>` ต้องเป็น core → ui → tabs → app |
| `css/style.css` | สีโหมดมืด/สว่าง + สไตล์ที่ใช้ร่วมกัน (ลูกบอลเลข, ฟอนต์) | ค่าสีแต่ละโหมดอยู่บนสุดของไฟล์ |
| `css/app.css` | Tailwind ที่ build แล้ว (สร้างจาก `npm run build:css`) | ห้ามแก้ตรง ๆ |
| `tailwind.config.js` | ตั้งค่า Tailwind: ชื่อสีและฟอนต์ | — |
| **ข้อมูลผลรางวัล** | | |
| `data/draws.json` | รางวัลหลักทุกงวด (รางวัลที่ 1, เลขหน้า/ท้าย 3 ตัว, ท้าย 2 ตัว, ลิงก์ PDF) | สร้างโดยสคริปต์ ห้ามแก้มือ |
| `data/full/<ปี ค.ศ.>.json` | รางวัลที่ 2–5 และข้างเคียง แยกรายปี โหลดเฉพาะตอนตรวจเลข 6 หลัก | สร้างโดยสคริปต์ |

| `.github/workflows/update-draws.yml` | ตั้งเวลาดึงผล + commit + deploy | เวลา cron |
| `.github/workflows/deploy.yml` | deploy ขึ้น GitHub Pages | — |
| **ตรรกะ (ไม่มีโค้ดหน้าจอ)** | | |

| `js/core/draws.js` | โหลดผลจริง / ผลที่ผู้ใช้กรอกเอง / ข้อมูลตัวอย่าง (เมื่อโหลดไม่ได้) | ลำดับความสำคัญของแหล่งข้อมูล |

| `js/core/saved.js` | เลขที่บันทึก และสถานะ ถูก/ไม่ถูก/รอผล | — |
| `js/ui/components.js` | toast, ปุ่มคัดลอก, ลูกบอล, ปุ่มตัวเลือก | — |

## หมายเหตุ

- ผลรางวัลมาจาก API ที่หน้าเว็บ glo.or.th ใช้เอง ไม่มีเอกสารทางการ ถ้า GLO เปลี่ยนรูปแบบ สคริปต์จะหยุดโดยไม่เขียนข้อมูลเสีย และ workflow จะขึ้นสีแดงในแท็บ Actions ระหว่างนั้นกรอกผลเองได้ในแท็บตรวจรางวัล
- สคริปต์เว้นระยะ 0.5 วินาทีต่อคำขอ เพื่อไม่ให้เว็บ GLO ทำงานหนัก
- งวด 16 เม.ย. – 16 พ.ค. 2563 ถูกยกเลิกช่วงโควิด จึงไม่มีในข้อมูล
